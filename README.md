# BankingAnalyzer

## Веб-страницы
### Описание
Этот проект предоставляет API для анализа данных о транзакциях пользователя с расчетом общей суммы расходов и поступлений, а также отображением информации о курсах валют и стоимости акций из S&P500. С помощью входной даты и необязательного диапазона временного интервала (неделя, месяц, год или все данные до указанной даты), API генерирует JSON-ответы для двух страниц:

1. Главная страница
2. Страница "События"

Каждая из этих страниц включает в себя информацию о расходах, поступлениях, курсах валют и стоимости акций на основе данных, извлеченных из файла транзакций.

## Структура проекта

### Файлы проекта:

- `src/main.py`: Основной файл с функциями для обработки данных и генерации JSON-ответов.
- `src/views.py`: Модуль, содержащий функции для работы с данными, фильтрации транзакций и формирования информации о курсах валют и акциях.
- `src/external_api.py`: Модуль для получения данных о курсах валют и стоимости акций.
- `src/utils.py`: Модуль для вспомогательных функций, таких как обработка дат, чтение файлов и вычисление фильтрации.
- `src/user_settings.json`: Файл настроек пользователя, содержащий информацию о валютных курсах и акциях для отображения на веб-странице.

###Требования:

- `pandas`: Для работы с табличными данными.
- `json`: Для работы с форматированием JSON.
- `datetime`: Для работы с датами.
- `requests`: Для отправки запросов к внешним API.
- `logging`: Для ведения логов.
- `pytest`: Для тестирования функций.

## Сервисы

### Описание проекта
В данном проекте реализованы сервисы для работы с транзакциями. Основные функции включают в себя:

- Анализ категорий для кэшбэка.
- Копилка для округления трат и накопления средств.
- Поиск транзакций по ключевым словам и телефонным номерам.
- Поиск транзакций с переводами физическим лицам.
- Сервисы используют элементы функционального программирования, такие как map, filter, и lambda для обработки данных и возврата результатов.

###Требования:

- `json`: Для работы с JSON-данными.
- `re`: Для регулярных выражений.
- `datetime`: Для работы с датами.
- `itertools`: Для группировки данных.
- `operator`: Для сортировки данных.
- `logging`: Для ведения логов.
- `pytest`: Для тестирования.

## Отчеты
Этот модуль предназначен для формирования и сохранения отчетов по транзакциям.

Функция `spending_by_category()` анализирует расходы по указанной категории за последние 3 месяца и сохраняет результат в JSON-файл с помощью специального декоратора `save_report`.

## Установка

Для установки зависимостей используйте [Poetry](https://python-poetry.org/).

### 1. Убедитесь, что у вас установлен Python 3.8 или выше.

### 2. Установите Poetry, если он еще не установлен:
```bash
pip install poetry
```

### 3. Клонируйте репозиторий:
```bash
git clone https://github.com/annatereshonok/BankingAnalyzer.git
cd BankingAnalyzer
```

### 4. Установите зависимости:
```bash
poetry install
```

### 5. Активируйте виртуальное окружение:
```bash
poetry shell
```

## Тестирование

Этот проект использует `pytest` для написания и запуска тестов.


## Запуск тестов

Для запуска всех тестов выполните следующую команду:

```sh
pytest
```

## Покрытие кода тестами

Для проверки покрытия кода тестами можно использовать `pytest-cov`:

```sh
pytest --cov=src
```

Где `src` — папка с исходным кодом.

## Логирование и отчеты

Для генерации HTML-отчёта о покрытии выполните:

```sh
pytest --cov=src --cov-report=html
```
